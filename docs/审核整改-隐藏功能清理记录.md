# 审核整改：隐藏功能清理记录

日期：2026-09-04

针对 App Store Guideline 5.6 的反馈，对 iOS 客户端进行了静态排查和清理。当前版本不再根据审核状态、用户等级或服务端开关向审核期间隐藏功能。

## 已清理内容

1. 删除直播间内按等级显示小游戏入口的逻辑，包括 show_game_level 相关配置和等级判断。
2. 删除直播间小游戏列表请求、小游戏入口菜单点击和小游戏跳转参数的 iOS 客户端使用。
3. 删除直播间贴片通过 opengame、game_url 触发小游戏的入口。
5. 删除个人中心收益、提现入口的客户端路由，并移除个人中心接口中用于区分审核版本的 version 参数。
6. 删除 iOS 客户端从远程 host_config.txt 获取并切换 API 域名的逻辑，生产 API 地址固定配置，测试地址仅在 Debug 构建使用。

## 具体修改明细

### 1. 直播间小游戏

- Classes/Live/Controller/CameraViewController.m
  - 删除进入直播间后请求小游戏列表的调用。
  - 删除更多菜单中小游戏按钮的点击分支。
- Classes/Rest/Controller/GameAudienceViewController.m
  - 删除进入直播间后请求小游戏列表的调用。
  - 删除更多菜单中小游戏按钮的点击分支。
- Classes/Rest/Controller/BaseLiveViewController.m
  - 删除 loadGame 中根据 game_url 加载全屏小游戏的逻辑。
  - 删除贴片 app_open=game_url 和 app_open=opengame 的处理。
  - 保留的小游戏历史方法目前没有任何入口调用。
- Classes/Rest/View/MoreBtnView/TheMoreView.m
  - 删除小游戏菜单点击后调用 selectGameBtnAction: 的分支，统一按普通菜单处理。
- Classes/Live/Model/AnchorModel.h
  - 删除 game_url 字段。
- 以下页面不再接收或写入服务端返回的 game_url：
  - AppDelegate.m
  - StartLiveViewController.m
  - UserProfileViewController.m
  - LiveLatestListViewController.m
  - LiveFollowListViewController.m
  - HomeSearchViewController.m
  - LiveHotListViewController.m

### 2. 等级和审核差异化逻辑

- Common/RootHttpHelper.m：删除 show_game_level 配置写入；show_info_level 相关配置保留。
- AppDelegate.m：删除启动时清理和读取 show_game_level 的逻辑。
- Classes/User/Controller/ProfileTabViewController.swift：
  - 移除个人中心接口请求中的 version 审核版本参数。
  - 收益、提现相关标签不再生成菜单。
- Common/UserMenuBridge.m：删除 income 菜单路由。

### 3. 网络和域名配置

- AppDelegate.m：
  - 删除从远程 host_config.txt 获取 API 域名的逻辑。
  - 生产环境固定使用 https://m.cxlzc.com/。
  - 测试域名仅在 DEBUG 构建使用。
  - 网络判断改为使用 KSYReachability，不再通过远程配置是否返回内容判断网络。

## 保留内容

直播、聊天、礼物、PK、用户资料、正常活动页及普通 Web 页面跳转均属于产品公开功能，未做审核期间差异化处理。

## 验证

已对 iOS 源码进行关键词和调用链搜索，确认上述功能不再有可见入口或远程触发入口；小游戏相关历史方法仍保留在旧代码中但已无入口调用，后续可在确认无 XIB/Storyboard 绑定后彻底移除。
